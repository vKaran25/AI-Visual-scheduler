# Django Post App 🚀

A beginner-friendly Django project built while learning from Chai aur Code YouTube tutorials. This app allows users to create, view, edit, and delete text-based posts. Includes basic user authentication and authorization to manage access.

---

## 🔧 Features

- 📝 **CRUD Operations** for posts (Create, Read, Update, Delete)
- 🔐 **User Authentication** (Signup, Login, Logout)
- ✍️ Only **logged-in users** can create or edit/delete their own posts
- 🌐 **Read-only access** to other users' posts
- 🔍 **Search functionality** (in progress)
- 🧩 Planned integration with **React** and **TailwindCSS** for a modern frontend
- 📦 Project is structured for easy local setup
